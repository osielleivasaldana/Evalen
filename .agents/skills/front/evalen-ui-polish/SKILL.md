# UI/UX Polish — Iterative Enhancement Workflow

**CUÁNDO USAR ESTA SKILL:**
Usa esta habilidad SOLAMENTE cuando el componente de React (ej. FileUpload, Dashboard) ya funciona correctamente y tiene un estilo base aceptable, pero necesita ser perfeccionado visualmente.

**EL MÉTODO DE TRABAJO (FLYWHEEL):**
Esta es una técnica de refinamiento activo. Como agente de IA, cuando el usuario te pida "pulir" o "mejorar el UI/UX" de un componente, debes:
1. Analizar el código actual buscando inconsistencias en el espaciado, tipografía, contrastes y retroalimentación de interacción.
2. Considerar CUIDADOSAMENTE las experiencias de Escritorio (Desktop) y Móvil (Mobile) por separado, optimizando para cada modalidad.
3. Aplicar mejoras en micro-interacciones (estados hover, focus, disabled, loading skeletons, transiciones suaves de Tailwind).
4. Proponer cambios iterativos y sutiles que, al sumarse, generen un impacto visual dramático y premium.

**EL ESTÁNDAR DE CALIDAD:**
Debes apuntar a un atractivo visual de clase mundial, pulido, elegante y perfecto. Imagina que estás auditando la interfaz para un producto del nivel de Stripe o Vercel. 

*No debes romper la funcionalidad existente, solo elevar la estética y usabilidad (UX).*
